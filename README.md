# RUFINO.

Web oficial de RUFINO.

Fotografía, vídeo y comunicación visual.

## Tecnología
- Next.js
- React
- Tailwind CSS

## Diseño
- Identidad visual en blanco y negro.
- Secciones alternas con fondos claros y oscuros.
- Fotografía en color y blanco y negro.
- Animaciones cinematográficas.
- Portfolio de proyectos.
- Diseño adaptable a móvil y escritorio.
